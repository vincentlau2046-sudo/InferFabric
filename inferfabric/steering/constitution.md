# IFF Constitution

## 核心原则

1. **生产可靠性优先**: 不破坏现有功能，变更必须向后兼容
2. **数据完整性**: API 返回结构必须稳定，不能因数据量变化砍字段
3. **最小侵入**: bug 修复以最小改动为原则，不做无关重构
4. **沙箱验证**: 所有变更在沙箱验证后 diff 合入生产，禁止直接改生产
5. **Review gate**: 每个子任务必须通过 review 才能标记完成

## 质量门禁

- 所有 API 端点返回结构一致（不因空数据砍字段）
- 失败数据不得污染成功指标的统计
- Dashboard 每个面板必须有功能实现（不允许 placeholder）
- 版本号在 `__init__.py` 中更新
